# hydrogrow
**HydroGrow** adalah aplikasi pembalajaran dan manajemen budidaya tanaman pangan mandiri berbasis **Flutter**. Aplikasi ini dirancang untuk membantu pengguna—mulai dari pemula hingga hobiis—belajar menanam, merawat, dan memantau tumbuh kembang berbagai jenis tanaman pangan secara mudah dan terstruktur.
